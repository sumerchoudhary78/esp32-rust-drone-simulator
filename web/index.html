    Simulation fixture only:

    Functional device models and approximate thrust/battery behavior. No RF, electrical transients, brushless commutation or cycle-accurate timing. Use firmware you trust with this local native emulator. Match A → A, B → B, C → C for the fixed propeller directions.

    STABILIZATION

    Tune the inner rate loop.

    Outer angle control requests a body rate. These gains drive the inner PID, followed by the X motor mixer. Disarm before applying changes.

    Simulation gains only. The motor curve, frame inertia and sensor noise on a real build will differ.

    ENVIRONMENT

    Put the link under pressure.

    Commands delayed by 500 ms or more expire. Wind causes drift: this controller stabilizes attitude and has no position hold.

    FAULT INJECTION

    Know what happens when it fails.

    Switch on a fault and observe the actual controller response. Faults stay enabled until you clear them or reset the workspace.

    Failsafe policy: cut all motors. An airborne quad will fall. Automatic safe landing needs additional sensing and a different policy.

    Every state change, recorded.

    01

    Let the IMU settle.

    The virtual ESP32 boots disarmed and gathers 500 stationary sensor samples. Preflight turns green after calibration and a fresh controller heartbeat.

    02

    Arm, then take off.

    Keep throttle at zero. Select Arm motors, then Take off. The simulation-only altitude helper climbs to your target height.

    03

    Try a small movement.

    W/S pitch forward/back; A/D roll left/right; Q/E yaw. Sticks and keyboard return attitude commands to center. Position may keep drifting because there is no GPS position hold.

    04

    Disturb. Observe. Recover.

    Apply an angular disturbance, watch the attitude plot, then land. Try link loss in Control tuning. After a failsafe, clear the fault and select Acknowledge & disarm before rearming.

    05

    Fly from Android.

    Run the server with cargo run --release -- --bind 0.0.0.0:8787. Open your computer's LAN address on your phone, on the same trusted Wi-Fi. Select Take control if another browser owns the controls.

    Use the responsive controller at /controller. A native Rust + Slint controller is also included in the repository.

    06

    Understand what this proves.

    This lab tests shared Rust control logic, command validation and failsafe transitions against an approximate quadcopter. It does not qualify hardware, prove real-time deadlines or replace propellers-off bench testing.

    Space triggers emergency stop. Closing or hiding the controller expires its commands. No physical motor can be controlled by this simulator.
